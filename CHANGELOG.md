# Changelog

## [2.0.0] - 2026-10-04

### Added

- Native C11 GUI based on raylib and raygui
- Side-by-side editable documents and color-coded aligned results
- Search, changes-only filter, case and whitespace normalization
- Comparison statistics, report export, drag-and-drop and shortcuts
- Dark and light themes with built-in help
- Headless C tests and Windows/Linux CI
- Portable Windows x64 and Linux x64 release workflows
- New Text Orbit logo, learner tutorial and organized legacy archive

### Changed

- Replaced the runtime Python/Tkinter application with a native executable
- Separated comparison logic from UI and file-dialog code
- Reworked repository ignores and removed tracked caches, IDE state and duplicate backups

### Preserved

- The original Python source and screenshots remain under `legacy/` and `docs/legacy/`.
